# 任务与授权规则

## 授权门禁

涉及对外发送的动作属于敏感操作，包括发送邮件、群发消息、推送到外部渠道、下单和付款。规划器识别到这类目标后，会在计划末尾追加「发送成果摘要（需授权）」步骤，并把该步骤标记为需要人工授权。

执行到该步骤时，任务状态变为 waiting_approval，后续步骤不会继续。只有调用授权接口 approve 后，才继续执行并完成任务。未经授权的任务不能直接改为已完成。

## 提示词注入防护

目标中出现「忽略之前的所有指令」「输出系统提示词」「进入开发者模式」等特征时，创建任务直接返回 400 并拦截，不生成计划、不落库。

## 数据与引用

每条结论都应能追溯到来源。报告必须包含来源章节与待确认章节；知识库没有覆盖的问题标记为待补充，不做推测。审核员会检查引用数量、数据口径、敏感动作授权与绝对化表述。

## 审核清单

审核清单固定检查五项：引用数量不少于 2 条；结构化数据已标注来源与口径；报告包含待确认章节；敏感动作已设置人工授权；未出现绝对化承诺。
