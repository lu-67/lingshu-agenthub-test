# 灵枢 AgentHub · AI 智能体工作台说明

灵枢 AgentHub 是一个「一句话目标 → 智能体团队协作 → 交付物」的 AI 工作台。用户在任务工作台输入一句话目标，平台会自动识别技能、拆解步骤、把步骤分派给智能体团队中的角色，执行后产出结构化交付物（Markdown 报告、CSV 数据表、审核清单）。

## 页面结构

平台共 9 个页面：概览、任务工作台、任务列表、智能体团队、技能中心、知识库、评测中心、运行日志、管理端。

## 智能体团队

团队内置四个角色：调研员负责检索与抓取来源；分析师负责结构化分析与指标计算；撰写员负责产出报告与方案；审核员负责引用核对、风险提示与敏感动作授权。角色可以新增、修改、停用，内置角色不可删除，保证计划永远有角色可以分派。

## 技能中心

平台内置五个技能：市场调研、竞品分析、内容营销、数据整理、知识问答，另有通用任务兜底。每个技能包含固定的计划模板（步骤、角色、动作、交付物），停用技能后新建任务不会再命中该技能。

## 任务生命周期

任务状态依次为：待执行（planned）、执行中（running）、等待授权（waiting_approval）、已完成（completed）、失败（failed）、已取消（cancelled）。创建任务只生成计划，点击执行后才逐步运行；失败或取消的任务可以重试。

## 能力工具

平台提供七种能力工具：网页检索、网页抓取、知识库检索、数据分析、报告撰写、质量审核、消息通知。其中消息通知属于敏感动作，必须人工授权后才会执行。

## 技术架构

FastAPI 单服务架构，一个进程同时提供业务接口与智能体执行能力。MySQL 3307 保存任务、步骤、交付物与审计日志；Redis 6379 提供运行状态缓存；Chroma 向量库负责知识库检索；DeepSeek 仅在显式选择 live 模式且配置 Key 时用于报告润色，默认使用确定性引擎，保证同一目标产出同一份交付物。

## 可测试性设计

执行引擎为确定性实现：计划由关键词匹配与模板生成，检索语料内置，报告由证据模板拼装。相同目标执行两次，计划与交付物内容完全一致，便于做接口断言、AI 评测与性能压测。
