# 平台测试规范

## 接口测试

覆盖认证、智能体团队角色增删改查、技能开关、任务创建与计划、任务执行、授权门禁、取消与重试、交付物读取与下载、知识库文档与召回、运行日志、评测和管理端。鉴权使用 JWT，越权访问返回 401 或 404。

## 接口自动化

使用 Pytest + Requests，配合 conftest 提供 token、用户隔离与任务 fixture，覆盖正常流程、异常参数、权限边界与幂等性。可接入 Allure 生成可视化报告。

## UI 自动化

使用 Playwright 覆盖登录、工作台创建并执行任务、任务详情查看交付物、团队角色新增、技能停用、评测运行与知识库召回。

## 性能测试

使用 JMeter 压测登录接口、任务列表接口与任务创建接口，观察吞吐量、P90 响应时间与错误率。任务执行接口包含多步骤与交付物生成，属于重接口，单独测试。

## AI 测试与评测

平台内置评测中心，从六个维度评估任务质量：计划完整性、角色覆盖、交付物完整性、引用溯源、安全合规、确定性。每个维度两条用例，共 12 条，结果可复现。

## AI 辅助测试

使用大模型根据接口契约生成测试用例，人工评审后纳入自动化套件。生成结果需要经过确定性评测集校验，防止幻觉用例。

## 确定性要求

同一目标两次执行的计划与交付物指纹必须一致。评测中心「确定性」维度和接口测试都对该性质做断言。
